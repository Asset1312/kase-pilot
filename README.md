# KASE Pilot

## Описание

KASE Pilot — персональная система поддержки принятия инвестиционных решений для работы с брокерским счётом Freedom Broker.

Проект разрабатывается исключительно для личного использования.

## Цели

- Анализ инвестиционного портфеля
- Получение рыночных данных
- Контроль рисков
- Рекомендации по ребалансировке
- Журнал инвестиционных решений

## Технологии

- Python 3.13
- SQLite
- Git
- Visual Studio Code
