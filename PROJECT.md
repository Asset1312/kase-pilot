Назначение проекта. KASE Pilot — персональная система поддержки принятия инвестиционных решений для личного брокерского счёта Freedom Broker. Проект создаётся только для собственного использования. Торговые операции не выполняются на первом этапе. Цели: анализ портфеля, история изменений, анализ эффективности, рекомендации по ребалансировке, контроль рисков, журнал решений. Принципы проекта. Безопасность важнее функциональности. Простота важнее сложности. Модульная архитектура. Все изменения фиксируются в Git. Никакие пароли и ключи не хранятся в коде. Этапы разработки. Этап 1. Структура, Git, виртуальное окружение, публичные рыночные данные. Этап 2. Подключение API, получение портфеля, сохранение в SQLite. Этап 3. Анализ доходности, дивиденды, рекомендации. Этап4. Подготовка заявок, подтверждение пользователем. Этап 5. Автоматическая торговля после тестирования. Архитектура. app, broker, strategy, risk, data, logs, tests, docs, config. Технологии Python3.13. Visual Studio Code, Git, SQLite, Ruff. Правила разработки. Одна задача на модуль, одна ответственность на класс, типизация обязательна. ROADMAP в формате чек-листа Журнал решений. 24.07.2026.

Выбран Python 3.13. Первая интеграция — Tradernet. База данных — SQLite. Git с первого дня. Автоматическая торговля запрещена на первом этапе. Архитектура должна позволять добавление других брокеров без переписывания логики. Давай договоримся: этот файл меняем только мы с тобой. Клод не должен самостоятельно его переписывать. Так мы сохраним концепцию проекта.
