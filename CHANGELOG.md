# CHANGELOG

Все значимые изменения проекта будут фиксироваться в этом документе.

---

## [0.2.0] - 29.07.2026

### Добавлено

- CLI-команды `portfolio` и `watch` для просмотра текущего портфеля
- CLI-команда `trades` для получения истории сделок
- CLI-команда `news` для получения новостей
- CLI-команды `market-status` и `top` для просмотра рыночных данных
- CLI-команда `orders-history` для получения истории заявок
- CLI-команда `corporate-actions` для получения корпоративных действий
- CLI-команда `price-alerts` для просмотра ценовых уведомлений
- CLI-команда `requests-history` для получения истории запросов
- CLI-команда `broker-report` для получения брокерского отчёта
- Структурированные broker- и application-слои
- Поддержка raw JSON-вывода для соответствующих CLI-команд
- Расширенная валидация аргументов CLI и тестовое покрытие

### Известные ограничения

- Команда `news` в настоящее время завершается ошибкой внутри внешнего
  Tradernet SDK; проблема не исправлена в KASE Pilot
